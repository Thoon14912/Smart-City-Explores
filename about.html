About Smart City Explorer

Project Purpose

Smart City Explorer is an ICT educational website created to demonstrate modern web design using Bootstrap components and responsive layouts. The website shows how different city zones can be presented through interactive web pages.

This website focuses on UI design, navigation and user experience.

Website Features

  • Responsive Bootstrap layout
  • Navigation bar with dropdown menus
  • Interactive components (accordion, cards)
  • Consistent design across pages
